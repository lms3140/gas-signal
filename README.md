# Gas Signal

천연가스 관련 외부 데이터를 한 화면에서 빠르게 참고할 수 있도록 정리한 대시보드입니다.  
이 프로젝트는 투자 결론을 대신 내리는 앱이 아니라, 현재 수급 흐름을 파악하기 위한 1차 참고 지표를 간결하게 보여주는 데 목적이 있습니다.

단순히 외부 데이터를 많이 나열하기보다, 실제로 의미 있다고 판단한 최소 지표만 남기는 구조를 선택했습니다.  
억지로 점수화하기보다 사용자가 직접 판단할 수 있는 핵심 지표 중심으로 정리한 점이 이 프로젝트의 방향입니다.

## 프로젝트 소개

Gas Signal은 천연가스 저장량과 HDD 데이터를 함께 보여주는 참고용 대시보드입니다.

초기에는 KOLD/BOIL과 연결되는 점수 패널도 포함했지만, 지표마다 비교 기준이 다르고 설명 가능성이 떨어지는 항목이 섞이면서 해석이 오히려 흐려진다고 판단했습니다.  
그래서 현재는 실제로 의미 있는 핵심 지표만 남겨, 더 단순하지만 설명 가능한 구조로 정리했습니다.

즉, 이 프로젝트는 단순 차트 앱이라기보다 외부 데이터를 가공해 현재 수급 흐름을 빠르게 읽을 수 있도록 만든 핵심 지표 중심의 참고 대시보드에 가깝습니다.

## 주요 화면 및 기능

- 최근 주간 천연가스 저장량 추이 차트
- 기준 주간 HDD 요약 카드
- HDD 평년 대비, 현재 저장량, 전주 대비 저장량 변화를 한 패널에서 정리
- 복잡한 점수화 없이 핵심 지표만 빠르게 확인할 수 있는 구조

## 핵심 지표 설명

### HDD 평년 대비

천연가스는 계절성 영향이 크기 때문에, 단순 절대값보다 동시기 기준 비교가 더 중요하다고 판단했습니다.  
이 지표는 기준 주간의 난방 수요 강도가 평년과 비교해 어느 정도인지 빠르게 파악하기 위한 값입니다.

HDD는 난방 수요를 나타내는 지표로, 65°F를 기준으로 평균기온이 낮을수록 값이 커집니다.  
예를 들어 평균기온이 55°F라면 HDD는 10입니다.

### 현재 저장량

저장량은 수급 상황을 해석할 때 기본이 되는 재고 지표라고 판단했습니다.  
대시보드에는 가장 최근 발표된 EIA 저장량 데이터를 표시합니다.

단, EIA 주간 저장량 데이터는 기준 주간 종료 후 다음 목요일에 발표되므로 체감상 갱신이 느리게 느껴질 수 있습니다.

### 전주 대비 저장량 변화

저장량의 절대 수준만으로는 최근 재고 흐름을 충분히 보기 어렵기 때문에, 직전 주 대비 증감도 함께 보여줍니다.  
이 값을 통해 최근 재고가 늘고 있는지, 줄고 있는지를 한 번에 확인할 수 있습니다.

## 점수 패널을 제거한 이유

초기 버전에는 KOLD/BOIL 점수 패널이 있었지만, 비교 기준이 애매한 지표가 섞여 있어 해석 일관성이 떨어졌습니다.

특히 아래 항목들은 최종적으로 제외했습니다.

- **저장량 vs 최근 1년 평균**  
  가스 저장량은 계절성이 강해 단순 평균 비교가 적절하지 않다고 판단했습니다.

- **HDD 전년 대비**  
  현재 시점의 수급 흐름을 보는 데에는 직접 지표로 쓰기 어렵다고 판단했습니다.

- **점수 패널**  
  점수화 자체가 사용자의 판단을 돕기보다 오히려 흐릴 수 있다고 판단해 제거했습니다.

결과적으로 현재 구조는 더 적은 정보를 보여주지만, 각 지표의 의미를 설명할 수 있고 비교 타당성도 더 분명한 상태입니다.
